# Image assets

Drop a JPEG named `<id>.jpg` in this folder and it becomes the portrait banner for that
node's details panel (expand it to centre-stage by clicking). A missing image falls back to
the original medallion. Only images you place here are used — none are fetched by the app.

`✓` = already present.
